# Flowers1

A cinematic Three.js generative-art floral heart. It is a static site with no build step.

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## Background music

Place your MP3 track in this folder and name it `musica.mp3`. The page tries to
start playback when it opens. If the browser blocks autoplay, use the music
button in the lower-right corner to start or pause playback.

## Deploy to Vercel

Import this GitHub repository in Vercel and keep the framework preset as **Other**. No build command or output directory is required.
